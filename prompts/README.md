# Prompts

The exact text of our coding prompts, as the [hackathon AI policy](https://interledger.org/es/hackathon/ai-policy/) asks.

- `NN-<topic>.txt`: one prompt per file, kept as it was typed (typos included), numbered in the order it was sent. They went to Claude Code in one session on 16–17 Oct 2026; the hook in `.claude/hooks/save_raw_prompt.py` adds each new prompt with the next number, named after its first words.
- `backend-service.txt` and `remove-asset-mismatch.txt`: the team's prompts for building the service and for removing the asset-mismatch rule.
